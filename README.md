A fully functional two-player simple chess game built using HTML, CSS, and JavaScript.

Inspired by classic chess games, this project was created to explore game development, 
logic building, and interactive web design. The game includes core chess mechanics along with special moves such as Castling, 
Pawn Promotion, and En Passant, with the overall logic spanning more than a thousand lines of code.

live demo: https://omarrafiq71.github.io/chess-project-1/
